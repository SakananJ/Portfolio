Embedded Systems

Embedded Boxing Video Game

A recreation attempt of Mike Tyson's Punch-Out!!, written in C for a 32-bit RISC-V architecture and running bare metal. No operating system and no game engine underneath it. Every piece of hardware the game touches is driven through memory-mapped I/O registers: the VGA pixel buffer, the keyboard, the interval timers, and the onboard LEDs are each written and read directly.

The fight runs on dual finite state machines (FSMs). One FSM controls the opponent through telegraphing, attack patterns, recovery, and hurt states; the other tracks the player's punching and dodging. Synchronizing the two is what makes an exchange work. The opponent's telegraph opens a window, and whether the player dodges into a counter or eats the punch falls out of which states the two machines are in when they meet. On top of that, I built hit-detection logic that tracks health for both fighters and drives knockdown states and referee counts, all paced by hardware timer polling.

Rendering uses double-buffered VGA graphics, so character sprites and screen transitions draw into an off-screen buffer and swap cleanly instead of tearing mid-frame. Round status and knockdowns map straight out to the board's onboard LEDs, and an external PS/2 keyboard handles user input. I developed and tested the game in CPUlator before running it on hardware.
